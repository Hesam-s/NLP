# NLP Repository

Welcome to the **NLP** repository maintained by **Hesam-s**! This repository contains various Natural Language Processing (NLP) projects, notebooks, custom datasets, and model implementations.

---

## 📂 Repository Structure

Below is an overview of the files and directories included in this repository[cite: 1]:

* **`Best Model/`**: Directory containing the best-performing trained model weights or artifacts[cite: 1].
* **`MAD-X.md`**: Documentation and notes regarding the MAD-X framework setup and implementation[cite: 1].
* **`MAD_X.ipynb`**: Jupyter Notebook containing code implementation and experiments for MAD-X[cite: 1].
* **`NPC_AI.md`**: Documentation detailing the NPC AI project design and details[cite: 1].
* **`NPC_AI.ipynb`**: Jupyter Notebook with the implementation and experiments for NPC AI[cite: 1].
* **`war_npc_dataset.csv`**: Dataset file containing data related to war NPCs used for training or evaluation[cite: 1].
